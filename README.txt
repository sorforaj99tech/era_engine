## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sorforaj99tech/era_engine.git
   ```

2. Navigate to the project directory:

   ```bash
   cd era_engine
   ```

3. Create a virtual environment:

   ```bash
   python -m venv env
   ```

4. Activate the virtual environment:

   ```bash
   env\Scripts\activate
   ```

5. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the project using its main entry-point file. For example:

```bash
python main.py
```

Adjust the command according to the actual project structure.
